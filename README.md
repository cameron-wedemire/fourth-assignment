# fourth-assignment
WASD for ship control

mouse controls the turret aim

cheat input H will skip current level

HOLD left click for your gun to fire (takes a bit to wind up)

the red blinking dot on the edge of the screen signals that a missile is about to come on screen

the blue dot shows the direction to the enemy station (the next levels station spawns once you destroy the last one)

stations can have multiple sections each with its own HP bar and hitbox, if it no longer has a turret it can no longer be hit so focus fire on the turrets
